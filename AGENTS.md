# Project Guidelines & Rules

## Project Context
- **Nature of Website**: Portfolio website (AarohaCare).
- **Tech Stack**: React.js + Tailwind CSS (pure frontend, clean & simple, no backend overhead).
- **Iterative Approach**: Build lean and iteratively — create components, utilities, and structure step-by-step only as needed for specific sections/designs rather than generating excessive boilerplate upfront.

## Git Commit & Push Workflow
- **Push Every New Section / Major Milestone**: Whenever a new section, substantive feature, major architectural update, or core component is completed, commit and push it to the remote repository.
- **Do Not Push Trivial Tweaks**: Avoid separate commits/pushes for minor style tweaks like text size, color changes, or tiny cosmetic edits during drafting. Bundle them into section/milestone commits.
- **Professional Commit Standards**:
  - Use conventional commit conventions (`feat:`, `fix:`, `refactor:`, `perf:`, `docs:`).
  - Write clear, professional, imperative-mood commit messages and clean descriptions.
